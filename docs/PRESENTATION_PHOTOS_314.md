The high-resolution Vision file is **not** upscaled to claim native 4K width.
1600px WebP derivatives are default; native-width larger WebP alternatives are
selected by srcset on high-resolution displays. Colour atmosphere is applied by
CSS, without changing downloaded originals.

WebP payloads are versioned in base64 under `local_app/web/presentation/` so the
GitHub text-file transport retains exact binary bytes. `manifest.json` records
size, native dimensions and decoded SHA-256. The local server verifies, decodes
and serves a fixed four-file allowlist; no network, data migration or writes to
projects. The final deliverable exporter writes ordinary `.webp` copies.
